# amanramanandsharma.github.io

Personal portfolio and resume site, served by GitHub Pages from this repo. Plain static HTML and CSS, no build step.

## Run
- Open `index.html` in a browser, or serve it: `python3 -m http.server 8000` from the repo root.
- No tests, no dependencies.

## Deploy
- Push to `main`; GitHub Pages publishes it. The repo must stay public for the site to be reachable.

## Key paths
- `index.html` the whole page (resume and project list live here).
- `assets/` images (jpg, png, ico) and the stylesheet.

## Gotchas
- Commit history is mostly "Updated Resume & Projects list": content edits go straight into `index.html`.
- Keep personal contact details intentional: the repo is public.
